#+title: djot-mode

A Tree-sitter major mode for [[https://djot.net][Djot]], independent of the optional =djot-modern= presentation package.  Requires Emacs 30.1+ with Tree-sitter. The major mode provides semantic highlighting, descriptive clickable links, native language highlighting, explicit source display, and structured heading/list/table/reference editing. Explicit local-image/math previews and official-renderer HTML export live in the optional, command-loaded =djot-preview.el= companion, not in the visual mode.

* Install

Put this directory on =load-path=, then configure the real Djot grammar:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/emacs-djot-mode")
(require 'djot-mode)
(add-to-list 'treesit-language-source-alist
             '(djot "https://github.com/jaybonthius/tree-sitter-djot"
                     "3025cd0c9fe0c0b27030725fbec27f8cab98b241"))
;; Once: M-x treesit-install-language-grammar RET djot RET
#+end_src

Grammar installation needs Git and a C/C++ compiler.  Emacs loads the installed shared library from its =tree-sitter= directory; use =treesit-extra-load-path= for another location.  =.djot= and =.dj= files select =djot-mode=.  Loading the package needs no renderer, browser, LaTeX installation, or modern package. Activation reports a useful error if the grammar is missing; it does not use a second, approximate parser.  The pinned fork is based on maintained upstream =https://codeberg.org/treeman/tree-sitter-djot= at =ed551f3= and corrects multiline reference destinations, inline URL continuation lookahead, empty table cells, EOF and indented table rows, nested/multiline quoted captions, quoted heading boundaries, falsely recognized ordered-list markers, display math in inline/EOF positions, verbatim/math termination at containing heading/list/quote boundaries, and bare code closers (including longer fences) in containers and at EOF. Existing older grammars remain usable for their supported syntax, but the mode detects missing destination-chunk support and refuses potentially truncated reference targets.  Reinstall the pinned grammar and restart Emacs to load the new library; loading another revision in the same Emacs process is not reliable.

* Document display

As in Org, links are descriptive by default, while emphasis markers remain visible.  A readable-document configuration is explicit and buffer-local:

#+begin_src emacs-lisp
(add-hook 'djot-mode-hook
          (lambda ()
            (setq-local djot-hide-markup t)
            (setq-local djot-descriptive-links t)
            (visual-line-mode 1)))
;; Optional presentation layer, installed separately:
;; (require 'djot-modern)
;; (add-hook 'djot-mode-hook #'djot-modern-mode)
#+end_src

The base mode inherits theme =outline-1= through =outline-6= colors.  Code is fixed-pitch and fontified by its real Emacs language mode; =elisp= aliases =emacs-lisp-mode=.  Only the trusted =djot-language-modes= mapping selects native major modes; customize it for additional trusted languages.  Raw blocks are literal, never language-fontified.  Unknown languages remain readable fixed-pitch source.  No document code, file-local variables, or source mode hooks are run while highlighting.

| Key       | Command / result                                      |
|-----------+-------------------------------------------------------|
| C-c C-o   | Open link, local file, heading anchor, or footnote      |
| RET       | Open when on link description                         |
| mouse-2   | Open the clicked link                                 |
| C-c C-b   | Return from a footnote to its reference                |
| C-c C-s   | Toggle explicit source display (all link/emphasis syntax) |
| C-c C-m   | Toggle matched emphasis-marker concealment             |
| C-c '     | Reveal source and move to the link destination         |

Movement never reveals concealed source.  Copy, search, undo and saving still operate on original Djot text.  Unmatched syntax, escapes, raw content and code contents remain visible; matched outer inline-code backticks follow =djot-hide-markup=.  Set =djot-descriptive-links= nil for visible link source. After changing a display option in an existing buffer, call =djot-refresh=. Imenu and the parser-backed heading commands below ignore heading-like text in code and treat multiline headings as one heading.

Opening links is explicit.  HTTP(S), mail and FTP links use =browse-url=; relative/local files use =find-file=.  Executable schemes such as =javascript:= and remote file URLs are rejected.  Reference labels are case-sensitive. No resource is fetched by fontification.

* Structured editing

Org/markdown-style commands operate directly on Djot source, with ordinary undo. Modern is not required.

| Key | Command / result |
|-----+------------------|
| TAB / S-TAB | In tables: align and next/previous cell; on headings: local/global fold cycle |
| RET | Continue a list, start a definition body, or insert a table row; otherwise newline |
| M-RET | Insert a sibling list/definition item; split ordinary item text at point |
| M-<right> / M-<left> | Indent/outdent the entire list item and its children |
| C-c C-c | Toggle/add a bullet checkbox; with prefix, remove it |
| C-c - | Cycle sibling list markers together |
| C-c C-n / C-c C-p / C-c C-u | Next/previous/parent parsed heading |
| C-c <left> / C-c <right> | Promote/demote a heading and its descendants |
| C-c C-a | Unfold all heading bodies |
| C-c C-l | Insert/edit an inline link; region supplies description |
| C-c C-x l / C-c C-x d | Insert reference link / create or update reference definition |
| C-c C-x r | Visit the explicit reference definition without opening its URL |
| C-c C-f | Insert a numbered footnote and visit its definition; prefix supplies label |
| C-c C-b | Return from footnote definition |
| C-c \vert{} | Align table without moving to another cell |
| C-c C-t i / C-c C-t d | Insert/delete table row; prefix inserts above |
| C-c C-t c / C-c C-t k | Insert/delete table column; prefix inserts after |
| C-c C-t - | Insert a Djot header separator below the current row |

Link descriptions retain their own RET-to-open binding; use M-x =djot-newline= when inserting a newline there. An empty list item ends the list. Ordered markers preserve their parsed decimal/alpha/Roman style; task continuation starts unchecked. Indenting inserts Djot's required blank line before a nested list rather than creating lazy paragraph text. A definition term's RET starts its indented body; M-RET starts the next term.

Heading TAB cycles folded / children / open; S-TAB toggles the overview. Movement alone never reveals source. Editing folded text signals a useful error rather than silently deleting it: explicitly unfold first. Links and heading navigation reveal their selected folded target; normal search can reveal a matching fold. Folding does not change markup concealment.

Table cells come from the pinned grammar, including zero-width empty cells and escaped/verbatim pipes. Alignment preserves captions, column alignment markers, quote/list prefixes and the final-newline state. Widths follow currently visible base text, like Org, and ignore modern/foreign padding. After changing explicit source display, realign if desired; toggling display itself never changes text or undo. TAB skips separator rows and adds a data row after the last cell. Commands reject malformed structures rather than guessing at syntax.

* Explicit previews and HTML export

Nothing is fetched, rendered externally or executed by fontification, redisplay or modern activation. These commands load =djot-preview.el= on demand; missing optional tools affect only the requested command, never ordinary editing.

| Key | Command / result |
|-----+------------------|
| C-c C-x i | =djot-display-inline-images=: display accessible local images |
| M-x djot-remove-inline-images | Remove local-image previews |
| C-c C-x m | =djot-preview-math=: math at point or in active region; prefix previews accessible buffer |
| M-x djot-clear-math-preview | Remove math previews, retaining cached SVGs |
| M-x djot-clear-math-cache | Remove previews and this buffer's private math cache |
| C-c C-x e | =djot-export-to-html=: official HTML beside the visited source |
| C-c C-x p | =djot-preview-html=: confirm trust, then open a temporary browser preview |

Local images require graphical Emacs image support. Relative paths, percent-encoded filenames and reference images resolve against the visited source directory (or =default-directory= for an unvisited buffer); remote files, URL authorities and non-file schemes are skipped without fetching. The explicit image command refreshes the image cache. Customize =djot-image-max-width= and =djot-image-max-height= for pixel limits. Normal link activation remains available on previewed images.

Math needs SVG support and real =latex= plus =dvisvgm= executables; customize =djot-latex-command=, =djot-dvisvgm-command= and =djot-math-scale= if needed. Only parser-confirmed, explicitly matched =$= / =$$= backtick fragments are previewed. Continuation indentation and actual enclosing quote/heading prefixes are decoded before rendering and cache lookup; literal greater-than operators and formula whitespace remain intact. Implicit block-boundary/EOF closers are never treated as matched source delimiters. The fixed preamble includes =amsmath=, =amssymb= and =xcolor=. LaTeX runs with =-no-shell-escape= in private temporary directories, with no document code blocks or document-supplied preambles executed. This is *not a sandbox*: untrusted TeX can read TeX-accessible local files and consume CPU, memory or disk. Preview only trusted math; =C-g= cancels synchronous rendering. Failures report =*Djot diagnostics*= and never replace source or successful exports.

Preview overlays preserve text, point, undo, search/copy and foreign overlays. Any source edit clears them conservatively, including edits to distant image references; explicitly rerun the command afterward. =djot-show-source= suspends/restores previews without rerendering or editing source. Font/theme/scale changes invalidate math previews rather than launching background LaTeX; explicitly preview again to use the new colors and scale. Successful SVGs are cached by exact TeX, display metrics and executable identity in a private per-buffer temporary directory, reused until cache clearing or buffer/mode teardown. Transient render files are removed on success, failure and cancellation. Modern-off retains previews; modern table layout measures their actual displays, while source alignment continues to ignore display padding/images and edits only text.

HTML export requires the official =@djot/djot= CLI (validated with version 0.3.2); set =djot-command= to its executable if not on =PATH=. The mode passes source through stdin with =--to html= and no filters or shell. The output is the official HTML fragment, unchanged and *not sanitized*, with no CSP inserted into ordinary exports. The default output is beside the source so relative resources work; when calling =djot-export-to-html= with a different directory, arrange relative resources there yourself. Unvisited buffers prompt for an output path; noninteractive calls must supply one. Existing output is replaced only after rendering and writing succeed, and export refuses to overwrite the source itself.

Browser preview is a separate trusted-document action with an explicit confirmation *each time*, before rendering or launching anything. It fails closed noninteractively and does not launch on refusal, export alone, or background actions. The temporary wrapper lives beside the source (or in =default-directory=) so relative resources resolve correctly; mode/buffer teardown deletes it. It contains a restrictive CSP denying scripts, objects, connections and form submissions while allowing local images and inline styles. CSP is only defense-in-depth, *not sanitization*: raw HTML, attributes and URLs remain official output, browsers differ, and meta-refresh or other navigation can still leave the document or cause network access. Trust the document before confirming; never assume that a local file or this CSP makes hostile HTML safe.

* Extension interface

=djot-mode= owns exactly one buffer-local =djot-parser=.  Extensions must reuse it.  The following interfaces are stable for the editing/presentation stages:

- =djot-node-at (&optional position type)=: smallest node or requested ancestor.
- =djot-node-children (node)=: named children in source order.
- =djot-node-valid-p (node)=: reject missing/error-containing/error-nested nodes.
- =djot-map-nodes (function &optional beg end types)=: visit intersecting named nodes, including ancestors; clip effects to the requested accessible range.
- =djot-link-destination (node)=: resolve link/image without resource access.
- =djot-refresh (&optional beg end)=: flush/ensure base fontification, preserving source, point, undo and modified status.
- =djot-after-fontify-hook=: functions receive BEG END after base faces, native tokens, and base overlays are installed.  Ranges may overlap/repeat.  They are fontification ranges, not necessarily complete syntax nodes.  Rebuild only your own decorations within them; never retain nodes across edits.

Base overlays have =djot-mode= property t and own the =djot-markup= invisibility category.  Extensions must not remove them.  Use separately tagged overlays or face remapping for visual effects, preserving native token foregrounds, links and concealment.  Do not replace the base font-lock rules or create a second parser.  Folding uses separately tagged =djot-fold= overlays and invisibility category; it never removes presentation overlays. Teardown removes only base overlays, folds and the base parser; the command-loaded preview companion separately owns =djot-preview= overlays and private temporary files. Extensions changing replacement displays without editing text must request =djot-refresh= for dependent layout. Semantic faces are =djot-heading-1= through =djot-heading-6=, =djot-code=, =djot-verbatim=, =djot-quote=, =djot-attribute=, =djot-marker=, =djot-language=, =djot-table=, =djot-list-marker=, =djot-link=, =djot-destination=, =djot-footnote=, =djot-emphasis=, =djot-strong=, =djot-highlight=, =djot-insert=, =djot-delete=, and =djot-math=.

* Development and provenance

#+begin_src sh
make check GRAMMAR_DIR=/path/to/tree-sitter
make oracle GRAMMAR_DIR=/path/to/tree-sitter \
  DJOT_ORACLE_MODULE=/path/to/node_modules/@djot/djot
make edit-oracle GRAMMAR_DIR=/path/to/tree-sitter \
  DJOT_ORACLE_MODULE=/path/to/node_modules/@djot/djot
make preview-oracle GRAMMAR_DIR=/path/to/tree-sitter \
  DJOT_ORACLE_MODULE=/path/to/node_modules/@djot/djot
DJOT_COMMAND=/path/to/djot make check GRAMMAR_DIR=/path/to/tree-sitter
make benchmark GRAMMAR_DIR=/path/to/tree-sitter
#+end_src

The gate runs warning-as-error byte compilation, strict Checkdoc and ERT using the real grammar.  Tests exercise public links, actual file visits, native code token faces, concealment, edits/undo, parser ownership and teardown, folded-edit protection, list/definition edits, table operations and one-step undo. =test/edit-gui.el= exercises real key bindings and verifies rendered table-bar pixel positions under light/dark themes in an isolated GUI; set =GRAMMAR_DIR= and =DJOT_GUI_DIR=. The editing oracle checks unchanged official HTML before/after table alignment in both display modes. The optional oracle target compares actual parsed destinations with the official =@djot/djot= 0.3.2 Node package; the normal check target needs no Node installation. Reference chunks with trailing whitespace follow that renderer: first-chunk trailing whitespace makes an ordinary paragraph; continuation-chunk trailing whitespace ends the preceding reference.  This is a documented compatibility difference from the syntax guide's leading/trailing-whitespace statement. No source whitespace is normalized or removed.
